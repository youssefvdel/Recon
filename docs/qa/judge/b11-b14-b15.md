## B14 — Tracker age is readable, and >7 days hides instead of greying — PASS

1. **8 days old** (`recon_live_player_stats_v3` entries `fetchedAt = now − 8d12h`):
   each team table reads **`Tracker · as of 8d — hidden`**; ACS/K/D/WIN%/HS% are **absent** (replaced
   by the sr-only "Tracker archived (8d) — values hidden"); rank, peak, level, Links and Skins stay
   visible. Evidence: `b14-archived.png`.
2. **2 hours old**: table reads **`Tracker · as of 2h`**; all Tracker values are visible
   (You 268 / 1.4 / 48% / 24%). Evidence: `b14-2h.png`. Note: the requested label "1h" is the
   formatter's output for a one-hour-old entry; a two-hour-old entry correctly reads `2h`.
3. **No timestamp**: table reads **`Tracker · age unknown — hidden`**, values hidden, never
   "just now". Evidence: `b14-unknown.png`.
4. **Past seven days the block is gone, not greyed**: no grey/disabled values — the cells are empty
   with a tooltip and the group header states the archive verdict (`b14-archived.png`).

Residual design note: the age is a **single stamp per team table**, not a stamp on every individual
Tracker number. That satisfies the `design-ui.md` appendix model ("one stamp: as of 2 Nov") and
keeps the screenshot readable; if the acceptance bar is literally per-cell stamps, this is the one
difference to decide.
