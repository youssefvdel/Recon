The one-page rationale

Ruled is a subtraction, not a reskin: it removes the card as a unit, removes tabs inside pages, removes whole pages from the nav, and spends the saved structure on rules, space and type that make one number readable at a glance.

Name & intent

  • RuledThe page is a ruled sheet: content separated by hairlines and space, never boxed.
  • Read, not scanOne primary number per sheet, read top-to-bottom in under 30 seconds.
  • Fewer placesThree destinations. Every former page is a section of one of them.

Type scale

  • Display56/1 · −0.035em · 560 — rank, result, never two per screen
  • Hero34 mono · RR, score, the number the page is about
  • Title24/1.15 · section headlines, match name
  • Body15/1.55 · prose, labels
  • Data13.5 mono · tabular-nums, right-aligned in tables
  • Micro10.5 · .13em uppercase · section marks, dt labels

Colour roles — one meaning each

  • Signalnow / live / the current round, page or row. Never decoration, never "important".
  • Verifieda value read back and confirmed (sync OK, GPU state, config read-back).
  • Unverifiedmissing, hidden, private, unreadable — a gap that must stay visible.
  • Ink ×3 + paper ×3everything else. Wins, losses, deltas and ranks are ink; outcome is encoded by position and fill.

Card policy

  • Zero cardsno boxed widgets in the main window. Separation = 1px rule + 24px space.
  • One filled surfacethe HUD panel, and transient overlays (⌘K, dialogs). Nothing else gets a background step.
  • Elevationone level: rule + paper step. No shadows, no glass, no backdrop blur anywhere.
  • Radius0. No pills; the party marker is a mono glyph, not a chip.

Nav / tab model

  • Nowrank, live lobby, last five. The default landing sheet.
  • Matchesone ledger; detail opens in place with a breadcrumb, no modal.
  • Machinedisplay, stretch, config editor, GPU, crosshair, sensitivity — all sections of one sheet, anchored.
  • Settingsa dialog on ⌘,, not a page. ⌘K reaches any section by name.

Build cost

  • Tokens + rail1 day — CSS variables, delete the card components.
  • Now sheet2 days — live band reuses the existing lobby rows.
  • Matches ledger1.5 days — one table, client-side sort; no virtualisation needed under 500 rows.
  • Report sheet3 days — round strip, scoreboard, duels, economy (data already in TrackerMatchDetail).
  • Machine consolidation3 days — move 8 existing views into anchored sections, delete page wrappers.
  • Total≈ 10.5 dev-days, no new dependencies, no new IPC fields.

Every field rendered here exists in src/types.ts: TrackerProfile (rank, rr, peak, wins, games), TrackerMatch (map, mode, agent, result, score, k/d/a, acs, hsPct, damage, startedAt), TrackerMatchDetail (players, rounds, kills, roundDetails.economy), LiveMatchState (tier/rank/rr, partyIndex, isIncognito, nameResolved, isTrnPrivate, trnState). No number is invented for this board; the values are samples of those fields.
